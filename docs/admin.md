# 관리자(Admin) 페이지

1.14.0에서 운영자 화면을 더했다. 주소는 서비스 주소 뒤에 `/admin`이다(예: `https://서비스-주소/admin`).

## 화면

| 탭 | 하는 일 | 자료 |
| --- | --- | --- |
| 사용 현황 | 방문자·재방문자, 선택지·이야기 추천 수, 메뉴·가게 클릭, 많이 고른 메뉴, 많이 찾은 검색어·음식군, 날짜별 추이 | `events` 표에서 요청마다 계산 |
| AI 결과 검수 | 이야기 추천의 입력 문장, AI 원래 출력, 서버가 해석한 조건, 추천 메뉴를 보고 맞음·틀림과 메모를 남긴다. 틀린 대화는 회귀 시험 후보(JSONL)로 내려받는다 | `chats` 표 |
| 피드백·신고 | 하단의 ‘피드백·신고’와 추천 결과에서 받은 의견을 보고 접수 → 처리 중 → 완료로 바꾼다 | `feedback` 표 |
| AI 운영 로그 | AI 호출마다 시각, 용도(조건 추출·매장 소개), 모델, 응답 시간, 입력·출력 토큰, 결과(성공·대기 초과·시간 초과·오류) | `ai_calls` 표 |
| 메뉴 관리 | 메뉴 검색, 숨김(추천·메뉴 상세에서 빠짐), 표시 이름 바꾸기, 메모 | `menu_overrides` 표 |
| 변경 이력 | 메뉴 수정, 검수, 피드백 처리, 권한 부여·회수를 누가 언제 이전 값 → 이후 값으로 바꿨는지 | `audit` 표 |

화면의 숫자는 모두 운영 DB에서 요청할 때 계산한다. 고정값이나 예시 데이터는 없다.

## 권한

- `/api/admin/*`는 로그인하고 관리자 권한이 있는 계정만 쓴다. 로그인하지 않으면 401, 일반 회원이면 403이다.
- 관리자 권한은 사이트에서 회원가입한 뒤 VM에서만 준다. 가입만으로 관리자가 될 수 없다.
- 관리자 권한 계정으로 서비스에 로그인하면 위쪽 '⚙ 관리' 버튼과 내 정보의 '관리자 페이지로 가기' 버튼으로 바로 넘어간다(1.14.2).

```sh
cd "$(systemctl show pickmenu-demo -p WorkingDirectory --value)"
# 서비스와 같은 회원 DB·계정 키·운영 DB 경로를 쓴다(값은 화면에 출력하지 않는다).
eval "$(systemctl show pickmenu-demo -p Environment --value | tr ' ' '\n' \
  | grep -E '^PICKMENU_(USERS_PATH|ACCOUNT_KEY_PATH|ADMIN_DB_PATH)=' | sed 's/^/export /')"
~/pickmenu/pickmenu/.venv/bin/python -X utf8 admin.py grant 아이디
# 회수: admin.py revoke 아이디, 목록: admin.py list
```

심사용 관리자 계정은 팀이 사이트에서 가입하고 위 명령으로 권한을 준 뒤, 아이디와 비밀번호를 심사 제출 양식으로만 전달한다(저장소·문서에 적지 않는다).

## 저장 위치와 개인정보

- 운영 DB는 회원 DB·카탈로그와 다른 SQLite 파일이다: `PICKMENU_ADMIN_DB_PATH`(운영: `~/.local/share/pickmenu/admin.sqlite3`, 권한 600). 릴리스 폴더 밖에 있어 버전을 바꿔도 유지된다.
- 사용 기록에는 회원 ID를 남기지 않는다. 방문자는 첫 화면에서 주는 임의 쿠키(`pickmenu_visitor`, HttpOnly, 1년)로만 센다.
- '검색어'는 대화 원문이 아니라 서버가 해석한 메뉴 검색어·음식군만 남긴다.
- 이야기 대화는 검수를 위해 회원 ID 없이 14일만 보관하고 지난 것은 지운다. 화면 대화 입력창 위에 이 내용을 안내한다.
- 사용 기록은 180일 뒤 지운다. 주소·좌표 검색어는 기존처럼 저장하지 않는다.
- 로그인 전에도 하단의 ‘피드백·신고’를 열 수 있다. 작성한 내용은 최대 300자이며 개인정보를 적지 말라고 안내한다. 추천 결과에서 보낼 때는 추천 방식과 대표 음식명만 덧붙인다.

## 메뉴 관리의 범위

원본 카탈로그(버전별 SQLite)는 바꾸지 않는다. 숨김·표시 이름은 운영 DB에 따로 저장하고 서버가 요청 때 적용한다. 따라서 카탈로그를 새 버전으로 바꿔도 운영자 수정이 유지되고, 되돌릴 때는 관리 화면에서 숨김을 풀면 된다. 영양값·매장 연결 같은 자료 수정은 기존처럼 카탈로그를 다시 만들어 릴리스로 배포한다.
